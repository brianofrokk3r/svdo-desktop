# SVDO Desktop wiki

[README](../README.md) · [Ticket guide](../docs/creating-tickets.md) · [Issue tracker](https://github.com/brianofrokk3r/svdo-desktop/issues)

This wiki is the general usage guide for SVDO Desktop. The repository itself is
primarily the place to create and track product tickets; use the
[ticket guide](../docs/creating-tickets.md) when something is missing or broken.

## Start here

1. [Getting Started](Getting-Started.md) — verify installation, launch Desktop,
   choose a custom port when needed, and initialize a workspace.
2. [Workspaces and Boards](Workspaces-and-Boards.md) — understand workspace
   scope, board stages, tickets, and local data.
3. [Tickets and Agent Runs](Tickets-and-Agent-Runs.md) — turn work into tickets
   and understand reusable Agents, run scope, and supported workflows.
4. [Git and Review Workflows](Git-and-Review-Workflows.md) — branches,
   worktrees, conflicts, and review handoff.
5. [Settings and Integrations](Settings-and-Integrations.md) — CLI providers,
   models, Agents, Skills, Cloud, standards, and automations.
6. [Troubleshooting](Troubleshooting.md) — common install, runtime, and run
   failures plus what to include in a report.

Installation commands and current platform requirements intentionally remain in
the [README](../README.md) so there is one concise compatibility entry point.
